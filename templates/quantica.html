4 Channel Quantizer

Each channel has a CV input with selectable range and a trigger/gate input. Channels can operate independently or be normalled together to create complex chords and harmonies.

Chord Sequencer

Quântica's inbuilt chord sequencer lets you record and playback patterns of up to 8 steps. The sequencer can be triggered by an external clock signal, with a configurable clock divider.

Arpeggiator

Each channel has an arpeggiator which is applied to the output note after quantization. Use an LFO to control the inversion of the chord, or use the normalisation to create more complex patterns

Chord Map

With an intelligent chord suggestion engine, Quântica makes it easy and fast to build great sounding chord progressions. Use the chord map to find inspiration for your next composition.

Key and Chord Library

With an inbuilt understanding of key and chord structure, and an intuative, responsive UI, Quântica is your guide to generative music.

Features

  • 4 independent quantizer channels which can also be chained to generate chords and harmonies
  • 1.28" touchscreen interface with an intuitive and highly responsive custom UI
  • Chord progression-based workflow, helps users quickly find chords that fit with a chosen key
  • Chord suggestion engine guides users towards chord sequences that will work well harmonically
  • Chord sequencer for storing and playing chord sequences. Externally clockable
  • Arpeggiator for each channel, that works alongside quantization and chord functions
  • Hardware buttons for the most common functions, plus a rotary encoder, allowing most functions to be accessed without touching the screen
  • Extensive library of keys and chord types
  • USB-C port for firmware updates
